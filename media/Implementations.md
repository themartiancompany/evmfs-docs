# Ethereum Virtual Machine File System reference implementations

There are two reference client implementations for the EVMFS,
one written in GNU Bash and Javascript and one fully written
in Javascript as a Node.js module compatible with web browsers
which is currently under development.

Both implementations are included in the EVMFS main git repository.
